# SOC-Lab-Nacoste-Associates

## Overview
This project simulates a real-world Security Operations Center (SOC) environment using a virtual enterprise network. The goal is to practice blue team security operations including logging, detection engineering, Active Directory management, and incident response.

---

## Lab Environment

- Virtualization: VirtualBox
- Domain Controller: Windows Server 2022
- Endpoint: Windows 11 Workstation
- Attack Simulation: Kali Linux (planned)
- Logging: Sysmon + SIEM (Splunk or equivalent)

---

## Network Architecture

- Internal Network: 10.10.10.0/24
- NAT Network: Northstar-LAN
- Domain: northstarhealth.local (planned)

---

## Lab Modules

- 01 Network Setup
- 02 Virtual Machine Deployment
- 03 Active Directory Configuration
- 04 SIEM & Log Analysis
- 05 Attack Simulation
- 06 Incident Response

---

## Goals

- Build enterprise-style Active Directory environment
- Generate and analyze security logs
- Simulate attacker behavior using MITRE ATT&CK framework
- Develop alert triage and incident response skills
