# Network Setup

This section documents the creation of an isolated NAT network in VirtualBox to simulate a corporate LAN environment for Nacoste & Associates Security Operations.

## Configuration
- Subnet: 10.10.10.0/24
- DHCP: Enabled
- Purpose: Internal lab communication between domain controller, endpoints, and SIEM
